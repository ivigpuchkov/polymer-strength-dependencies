# Регрессионный анализ временной зависимости прочности полимеров Epon и PMMA
В данной работе была построена временная зависимость прочности (зависимость максимального напряжения от времени, при котором происходит потеря прочности) и найдено инкубационное время смеси жидкой эпоксидной смолы Epon 826 с отвердителем DEA (Epon 826/DEA) на основе экспериментов по сжатию стержней на силовых машинах (квазистатические испытания) и стержнях Гопкинсона (динамические испытания).

Классический критерий разрушения не позволяет полностью описать временную зависимость, поэтому используется критерий инкубационного времени Петрова—Морозова, согласно которому разрушение наступает в момент достижения равенства в неравенстве

```math
\frac{1}{\tau} \int_{t-\tau}^{t} \frac{\sigma(s)}{\sigma_{\text{ст}}}\,\mathrm{d}s \le 1,
```

где $\tau$ — инкубационное время, а $\sigma_{\text{ст}}$ — предел статической прочности материала. В рамках этого подхода инкубационное время рассматривается как основная мера реакции на динамическое нагружение и считается константой материала. Именно этот подход позволяет построить динамическую ветвь прочности, которая подтверждается экспериментально.

Поскольку $\sigma_{\text{ст}}$ для полимеров не является постоянной материала, для корректного построения зависимости используется теория Журкова, описывающая термофлуктуационный механизм разрушения. Согласно данной теории, время жизни до разрыва деформированных межатомных связей

```math
t_{\text{кр}} = t_0 \exp\!\left(\frac{U_0 - \gamma\sigma_{\text{ст}}}{kT}\right),
```

где $t_0$ — период колебаний (принимался за $10^{-13}$ с), $(U_0 - \gamma\sigma_{\text{ст}})$ — энергия активации, $U_0$ — энергия связи. Произведение $\gamma\sigma_{\text{ст}}$ служит эквивалентом энергии деформации. Тогда

```math
\sigma_{\text{ст}} = \frac{U_0}{\gamma} - \frac{kT}{\gamma}\ln\frac{t_{\text{кр}}}{t_0}.
```

В предположении линейной одномерной упругости и постоянной скорости деформации, подставляя функцию напряжений $\sigma = \dot{\sigma}t$ в интегральный критерий и решая уравнение относительно момента разрушения, получаем временную зависимость прочности:

```math
\sigma =
\begin{cases}
\dfrac{2\tau}{t_{\text{кр}}}\left(\dfrac{U_0}{\gamma} - \dfrac{kT}{\gamma}\ln\dfrac{t_{\text{кр}}}{t_0}\right), & t_{\text{кр}} < \tau, \\[2ex]
\dfrac{2t_{\text{кр}}}{2t_{\text{кр}} - \tau}\left(\dfrac{U_0}{\gamma} - \dfrac{kT}{\gamma}\ln\dfrac{t_{\text{кр}}}{t_0}\right), & t_{\text{кр}} \ge \tau.
\end{cases}
```

При обработке экспериментальных данных с помощью алгоритма Левенберга—Марквардта определены параметры $U_0$, $\gamma$, $\tau$ и их 95% доверительные интервалы.

Инкубационное время составило $3{,}3 \pm 1{,}8$ мкс. Полученное значение согласуется с порядком величин, характерных для эпоксидных полимеров данной группы.
